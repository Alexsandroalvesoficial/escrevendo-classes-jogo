# Escrevendo as Classes de um Jogo

Projeto desenvolvido em JavaScript para o desafio prático da [DIO](https://www.dio.me/).

## Objetivo

Criar uma classe genérica chamada `Heroi`, com as propriedades `nome`, `idade` e `tipo`, além de um método `atacar()` que exibe uma mensagem de acordo com o tipo do personagem.

## Regras dos ataques

| Tipo de herói | Ataque |
|---|---|
| mago | magia |
| guerreiro | espada |
| monge | artes marciais |
| ninja | shuriken |

## Como executar

1. Instale o [Node.js](https://nodejs.org/).
2. Clone este repositório ou baixe os arquivos.
3. Abra a pasta do projeto no terminal.
4. Execute:

```bash
node index.js
```
